### 1. Permissions (`settings.json`)

許可待ちが発生したコマンド:
- `Edit` (ファイル編集時)
- `Bash(gemini *)` (Geminiレビュー依頼時)
- `Bash(sleep *)` (待機コマンド)

```json
{
  "permissions": {
    "allow": [
      "Edit",
      "Bash(gemini *)",
      "Bash(sleep *)"
    ]
  }
}
```

**理由**: Editは頻繁に使用するため、許可しておくと効率が上がる。geminiコマンドはsubagent-reviewスキルで使用するため許可推奨。

### 5. Hooks (`settings.json`)

**提案**: Rustファイル編集後に自動フォーマット

```json
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "if [[ \"$CLAUDE_FILE_PATH\" == *.rs ]]; then cargo fmt --quiet 2>/dev/null || true; fi"
      }]
    }]
  }
}
```

**理由**: CIでfmtチェックがあるため、編集時に自動フォーマットすると手戻りを防げる。
